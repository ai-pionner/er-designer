# ER Designer · 数据库关系设计器

一个单文件、零依赖、纯离线的 ER 图编辑器。双击 `index.html` 就能用，不需要安装、不需要后端、不联网，所有数据只存在你自己的浏览器里。

**在线使用**：<https://dilrabasgossipman.github.io/er-designer/>

## 为什么是单文件

整个设计器只有 `index.html` 一个文件（约 155KB），HTML + CSS + JS 全部内联，用原生 SVG 手绘渲染。可以放在 U 盘里、发到群里、扔到任意静态服务器上，断网也能跑。

## 功能

**模块（业务域）**
模块是图上的分区容器，用来圈住同属一个业务范围的表。可改名、可整体拖动、可换配色。模块之间不允许重叠，新模块落点撞上已有模块时会自动就近避让。模块的尺寸由内部内容决定——有表时框就是所有表的包围盒，四边各留 14px；没有表时保持 300×158 的默认大小，方便先占位再往里填。

**表与字段**
表只能放在模块内部。支持增删字段、拖动排序，每个字段可标记 PK / 主键、FK / 外键、UK / 唯一、非空，并填写中文名、数据类型、默认值和注释。表与表之间同样不允许重叠。

**类型下拉**
内置 8 组共 51 个常用 SQL 类型（整数、小数、字符、时间、布尔/位、二进制、JSON/XML、其他），带搜索过滤，也允许直接手写任意类型名。下拉会判断下方空间，不够时自动朝上展开。

**关系连线**
三种关系：1:1、1:N、N:N。连线挂在**列级锚点**上——主键行右端、外键行左端各自会冒出连接点，因此能表达"订单表的 customer_id 指向客户表的 id"这种精确关系，而不只是表对表。

**改线不用删了重画**
按住连线拖走一端即可改连；拖到空白处就是断开。只有点连线上的标签才会弹出关系类型选择器，点线本身只是选中——避免误触。

**对齐辅助线**
拖动模块时会与其它模块的左缘、中线、右缘自动吸附；拖动表时会与画布上任意其它表（含其它模块里的表）的同类参考线吸附。吸附成立时画出蓝色虚线加两端短刻度，松手即消失。容差 7 个屏幕像素，所以不同缩放下手感一致。按住 <kbd>Alt</kbd> 可临时关闭吸附，用于精确对位。

**模块四向生长**
往模块的上、下、左、右任意方向加表，模块会朝那个方向撑开，而不是只会向下长；放下前会画出生长预览。下方被占满时依然可以往上方放。

**导入导出**

- 导出 SVG：文件里内嵌完整模型（`<metadata>`），重新导入可继续编辑，往返不丢数据
- 导出 PNG：按 2 倍像素密度输出，适合贴文档
- 导入 DDL：粘贴 `CREATE TABLE` 语句自动建表建字段，支持 MySQL / PostgreSQL / SQL Server，字段中文名自动取自 `COMMENT`
- 拖入 `.svg` 或按 <kbd>Ctrl</kbd>+<kbd>O</kbd> 也能导入

**编辑体验**
撤销 80 步、自动保存到 localStorage（键名 `er-designer-v1`）、画布缩放平移、从右侧组件库拖出时预览按当前缩放比例显示、拖拽时不会误选中文字。

## 快捷键

| 操作                | 快捷键                                                       |
| ------------------- | ------------------------------------------------------------ |
| 撤销 / 重做         | <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> 或 <kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| 删除选中            | <kbd>Del</kbd> 或 <kbd>Backspace</kbd>                       |
| 关闭弹窗 / 取消选中 | <kbd>Esc</kbd>                                               |
| 导入 SVG            | <kbd>Ctrl</kbd>+<kbd>O</kbd>                                 |
| 适应画布            | <kbd>Ctrl</kbd>+<kbd>0</kbd>                                 |
| 临时关闭对齐吸附    | 拖动时按住 <kbd>Alt</kbd>                                    |
| 缩放 / 平移画布     | 滚轮 / 在空白处拖拽                                          |

## 数据在哪

不存在服务器上，也没有账号体系。模型保存在浏览器 localStorage 的 `er-designer-v1` 里，换浏览器或清缓存就会丢。重要的图请用「导出 SVG」存成文件——那个文件本身就是完整备份，随时可以导回来。

## 浏览器兼容

现代 Chromium 内核浏览器（Chrome / Edge）即可。使用了原生 SVG、Pointer Events 和 localStorage，不需要任何 polyfill。
